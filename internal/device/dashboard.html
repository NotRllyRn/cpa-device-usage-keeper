Device Usage Keeper

Independent fork of CPA Usage Keeper. Device aggregates, never proxy requests.

Token stays in memory only. Use HTTPS through your reverse proxy. Find the initial token in the plugin data directory's private admin-token file.

Model Pricing Settings

Keeper rates in USD per million tokens. Costs are API-equivalent estimates under current settings, not subscription bills. Editing a rate immediately changes historical estimates.

All rates are required; explicit zero means free. Request-dependent pricing branches/rules are unavailable for daily aggregates. Sync Prices and request recalculation are not exposed.
